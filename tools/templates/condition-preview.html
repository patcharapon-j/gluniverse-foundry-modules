Token Condition Directions

Four ways to draw the conditions a token is carrying. Every bar and every plate on this page is a compiled fragment shader, not CSS — the health bars are the module's own shader.mjs running unmodified, and the condition plates are a new shader written in the same material: the same layered body, the same single hard specular, the same chamfer, the same bloom. They share one HDR buffer and one bright-pass, which is the only honest way to judge whether they belong to each other. Hover a scene to expand it; the controls drive real transitions.

The tone system

PF2e ships no positive/negative flag on a condition — CONDITION_SLUGS is a flat set of 44 strings and nothing on the document says whether it is good news. Colour therefore means nothing until we decide what it means, and that decision outlives the geometry: a GM learns “violet means an action was taken away” exactly once. Six tones, held to two rules — each has to survive at a 14px plate on a dark map, and none of them may be the suite's gold, which is spent on chrome and nothing else.

N carries a counter — the twelve valued conditions, plus a damage formula on persistent damage.

What I need from you

Placement

Flank (A), top edge (B), ring (C) or spine (D). The one choice that is hard to reverse — the rest can ship as settings.

Labels

Always named (D), expand-on-hover (A), or icon-only for good (B and C — neither has the width for a word). This is the axis that decides whether a new player can use the thing.

Tone

Keep six tones, collapse to three (bad / sensory / good), or drop colour semantics entirely and let every plate share the accent.

Motion

The print, the hitstop and the peril breath are all shared with the bar — the breath is literally the same uTime * 1.35 clock. The ring's travelling specular is the only always-on loop, and it is optional.

Say a letter and I'll build it. Mixing is a complete brief — “B's placement, D's labels, A's plate” is enough to start from.

Behind all four: conditions come from actor.conditions.active, keyed by slug, with the counter from condition.badge — PF2e's own active getter already resolves the system's override rules, so “unconscious hides paralyzed” is free. Foundry's icon layer is switched off with renderable = false and never visible, because visible is the permission answer and writing to it is how a hidden creature's state leaks. The shipped version samples PF2e's own condition art through the same etch path these glyphs use.
